# E-Commerce Sales Performance Analysis

## Project Overview
This project analyzes Amazon e-commerce sales data to identify sales trends, product performance, order status patterns, fulfilment performance, and geographic sales insights.

## Objectives
- Analyze overall e-commerce sales performance.
- Identify top-performing product categories.
- Study monthly sales trends.
- Analyze sales performance across different states.
- Compare Amazon and Merchant fulfilment performance.
- Analyze order status and cancellation patterns.
- Generate actionable business insights and recommendations.

## Dataset
Source: https://www.kaggle.com/datasets/thedevastator/unlock-profits-with-e-commerce-sales-data

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Analysis
- Sales by Product Category
- Monthly Sales Trend
- Top States by Sales
- Sales by Fulfilment
- Order Status Distribution
- Cancellation Rate
