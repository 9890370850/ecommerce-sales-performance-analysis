# E-Commerce Sales Performance Analysis

## Project Overview
This project analyzes Amazon e-commerce sales data to identify sales trends, product performance, order status patterns, fulfilment performance, and geographic sales insights.

## Objectives
- Analyze overall e-commerce sales performance.
- Identify top-performing product categories.
- Study monthly sales trends.
- Analyze sales performance across different states.
- Compare Amazon and Merchant fulfilment performance.
- Analyze order status and cancellation patterns.
- Generate actionable business insights and recommendations.

## Dataset
Source: https://www.kaggle.com/datasets/thedevastator/unlock-profits-with-e-commerce-sales-data

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Setup and Run Instructions
1. Install Python 3.x or open the notebook in Google Colab.
2. Install the required Python libraries using:
   `pip install -r requirements.txt`
3. Open the project notebook.
4. Upload the `Amazon Sale Report.csv` dataset when running the notebook in Google Colab.
5. Run the notebook cells from top to bottom.
6. The notebook performs data loading, cleaning, analysis, KPI calculation, and visualization.

## Key Analysis
- Sales by Product Category
- Monthly Sales Trend
- Top States by Sales
- Sales by Fulfilment
- Order Status Distribution
- Cancellation Rate
- B2B and B2C Sales Analysis
- Product and SKU Performance

## Backend / Frontend / Model Information
This project is a Python-based data analytics notebook. It does not use a separate web frontend, backend server, or machine-learning prediction model. The analysis is performed using Pandas and Matplotlib in Google Colab/Jupyter Notebook.
